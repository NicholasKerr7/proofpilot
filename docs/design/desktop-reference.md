## Desktop Visual Direction

- Treat desktop as the full case command center while preserving the mobile and tablet workflows.
- Use the persistent left navigation rail, wide operational canvas, and denser multi-column layouts to reduce scrolling and navigation churn.
- Keep the dark graphite base, copper emphasis, functional progress treatments, compact typography, and restrained panel elevation.
- Prefer evidence/detail, checklist/requirement, packet/history, inbox/detail, and settings/summary split views where the references show them.
- Keep content readable at `1280 x 900` and `1440 x 1100`; cap long-form text and editor widths even when the application canvas is wider.
- Preserve visible keyboard focus, reduced-motion behavior, and full functionality without hover.

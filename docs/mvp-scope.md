# MVP Scope

ProofPilot starts with one case type: Account Ban / Appeal Builder.

## Supported First Use Cases

- PayPal account closure appeal
- Cash App account restriction
- Stripe account hold
- Social platform suspension
- Bank or payment account dispute

## Packet Sections

- Cover page
- Case summary
- User statement
- Timeline of events
- Evidence checklist
- Evidence index
- Supporting documents
- Next steps

## Evidence Types

MVP uploads currently support PDF, PNG, JPG, JPEG, TXT, and DOCX. Email exports, CSV, and XLSX come after the first packet flow is hardened.
